Codex

  1. Run both commands.
  2. Complete sign-in in the browser.
  3. Start a new session and run /mcp.

ChatGPT

  1. In ChatGPT, go to Settings → Connectors.
  2. Use the configured connector name and description, then paste the HTTPS MCP server URL.
  3. Start a new chat, choose the connector from the composer tool menu, and complete sign-in.

Claude Code

  1. Run the command.
  2. Run /mcp in Claude Code.
  3. Select the server and complete sign-in.

Cursor

Add to ~/.cursor/mcp.json or .cursor/mcp.json.

  1. Save the file.
  2. Enable the configured server in MCP settings.
  3. Complete sign-in in the browser.
